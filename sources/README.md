# Sources (raw, immutable)

Layer 1 of the wiki. Drop curated raw material here — PDFs, article clippings, book excerpts,
transcripts. **Never edit a file after it lands** — treat it as an immutable source of truth.

Cite source material from a note as `sources/<section>/<filename>` in the note's **Sources** section.
Organize by section, e.g. `sources/eq/`.

This directory is **not** rendered into the published site.
